AI Needs an SOP

The real problem only appeared after five scenarios worked.

2026-10-085 min

We have five AI scenarios running: bulk script generation, four-part video prompt storyboards, comment intent analysis on Douyin, batch re-edits across 102 accounts, and AI-assisted review in the weekly meeting. Every one produces results.

Then I wrote the hardest self-assessment of the year: all of it still depends on how I personally operate it. It is not yet a documented, transferable standard. If I leave, the knowledge leaves with me.

Personal tool versus team asset

A personal tool is judged by whether I can make it work. A team asset is judged by whether someone else can make it work following the document. The first needs one success. The second needs every condition written down: which model, which parameters, what to do when it fails, who checks the output.

  • Write it down and it exists
  • Every step needs a fallback — 'I usually know' is not a fallback
  • Results must be re-checkable, not just plausible
  • It is only really captured when I no longer remember it
Writing down 'from personal tool to team asset' excited me more than any KPI overshoot this year.
